# session-note

Claude Code 세션마다 노트 하나 — 해야 할 일·확인할 일을 나와 에이전트가 함께 적고 함께 완료 처리한다.

[English](README.md)

긴 세션에서는 일이 묻힌다. "그건 나중에 보자", "이거 맞나?", 하려던 후속 작업이 위로 밀려 올라가 사라진다. session-note는 세션마다 입력창 옆에 작은 할 일 노트를 둔다. 내가 직접 쓰고, 에이전트는 항목을 제안하고, 둘 다 완료 처리할 수 있다.

```
 노트 2  │  새 항목  토큰 만료 처리 확인                              추가   무시
❯ _
```

## 화면에서 보이는 것

- **띠** — 입력창 바로 위 한 줄. `노트 2`는 열린 항목 수다. `열기`를 누르면 옆 패널이 열린다.
  에이전트가 무언가를 제안하면 띠에 버튼과 함께 보인다.

  | 에이전트의 제안 | 띠에 보이는 것 |
  |---|---|
  | 새 항목 | `새 항목  <제목>   추가  무시` |
  | 열린 항목이 끝난 것 같음 | `끝난 항목  <제목>   완료  아직` |
  | 여러 개 | `새 항목 2 · 끝난 항목 1   보기`(패널을 연다) |

- **패널** — 터미널 오른쪽(창이 좁으면 입력창 위). 위에서부터 답하지 않은 제안, 열린 항목, `+ 새 항목`, 완료 묶음(`완료 N ▸`, 최근 5개, 그다음 `[더 보기 (N)]`).
  - `☐`을 누르면 완료, `☑`을 누르면 되돌린다.
  - 제목을 누르면 펼쳐져 내용, 추가 일시, `[수정]` `[삭제]`가 보인다(삭제는 한 번 더 묻는다).
  - 내가 직접 쓴 항목에는 `☺`가 붙는다.
- **`/note`** — 대화창에 줄을 남기지 않고 패널을 연다.

모든 조작은 마우스로 한다. 키보드는 제목·내용을 칠 때만 쓴다(Enter로 저장).

## 에이전트가 노트를 쓰는 방식

에이전트는 `note` 도구 하나를 받고, 도구 설명에 고정된 규칙을 따른다.

- **제안만 하고 정하지 않는다.** 대화에서 뒤로 미룬 일과 결론 없이 남은 확인 거리만 제안한다. 지금 바로 할 일, 스스로 정해도 되는 세부, 자기 작업 계획의 단계는 제안하지 않는다. "노트에 남길까요?"라고 묻지 않는다 — 제안은 내가 추가하거나 무시할 때까지 띠에 떠 있다.
- **작업을 마쳤을 때 대조한다.** 작업 하나를 마쳤거나 내가 "노트 확인해 줘"라고 하면, 열린 항목과 한 일을 견주어 끝난 것을 완료로 제안한다. 내가 시키지 않으면 직접 완료하지 않는다.
- **시키면 바로 한다.** "노트에 남겨 줘"면 항목을 추가하고, "그거 끝났어"면 완료한다.
- **늘 최신 노트를 안다.** 내가 패널에서 바꾼 것은 그 내용만 에이전트에게 전해진다(내 화면에는 안 보인다). 대화가 압축된 뒤와 `/resume`으로 돌아왔을 때는 노트 전체가 한 번 전해진다. 매 답변마다 넣지 않으므로 세션이 무거워지지 않는다.

## 설치

Claude Code 안에서:

```
/plugin marketplace add angar2/session-note
/plugin install session-note@angar2
```

또는 셸에서:

```sh
claude plugin marketplace add angar2/session-note
claude plugin install session-note@angar2
```

첫 명령은 이 리포를 플러그인 출처로 등록하고, 둘째 명령은 내 계정의 모든 세션에 플러그인을 설치한다.

화면 언어는 **English**(기본)와 **한국어** 중 하나다. `/plugin install`이 물어보고, 셸에서 설치할 때는 `--config language=한국어`를 붙이면 한국어가 된다. 언제든 `/plugin configure session-note@angar2`로 바꿀 수 있고, 노트의 항목은 그대로 남는다.

띠는 기본으로 배경색이 없다. 더 눈에 띄게 하려면 `/plugin configure session-note@angar2`의 **Band background**를 `Gray`(회색)·`Olive`(올리브)·`Wine`(와인) 중 하나로 고른다(`None`은 끈다). 색은 터미널 테마를 따른다.

## 노트는 세션을 따라간다

- 세션마다 노트가 따로 있다. `/clear`는 새 세션을 시작하므로 새 빈 노트가 되고, 옛 노트는 옛 세션에 남는다.
- `/resume`은 그 세션을 노트와 함께 다시 불러온다.
- `--fork-session`은 대화를 새 세션으로 이어 가므로 빈 노트로 시작하고, 에이전트에게도 그렇게 알린다.

## 노트가 저장되는 곳

세션마다 JSON 파일 하나:

```
~/.claude/plugins/data/session-note-angar2/sessions/<세션 ID>.json
```

파일은 그 세션에 첫 항목이나 첫 제안이 생길 때 만들어진다. 지난 세션의 노트는 지우지 않는다.

**플러그인을 지우면 노트도 지워진다.** `claude plugin uninstall session-note@angar2`는 이 폴더도 지운다. 남기려면:

```sh
claude plugin uninstall session-note@angar2 --keep-data
```

노트 파일을 읽을 수 없으면(깨진 JSON, 더 새 버전이 쓴 파일) 원본은 건드리지 않고 옆에 `<세션 ID>.unreadable-<일시>.json` 사본을 남긴 뒤 빈 노트로 시작한다.

## 한계

- **회사가 관리하는 Claude Code**: 회사가 Claude Code를 관리하는 환경에서는 세션 시작 신호가 개인이 설치한 플러그인에 오지 않는다. 그래서 `/clear`·`/resume` 때 노트가 바뀌지 않고, 압축 뒤 노트를 다시 전하지 못한다.
- **`/rewind`**: 대화를 되감으면 그 지점 뒤에 에이전트에게 전한 변경도 함께 사라지고, 플러그인에는 신호가 오지 않는다. 노트 자체는 되감기지 않으며, 에이전트는 `note` 도구로 다시 읽을 수 있다.
- **한 세션을 두 곳에서**: 같은 세션을 터미널 두 개에서 동시에 여는 것은 지원하지 않는다. 나중에 저장한 쪽이 이긴다.
- **호버**: 버튼 위에 마우스를 올렸을 때의 반전은 마우스 움직임을 넘겨 주는 터미널에서만 보인다.

## 필요한 것

- 플러그인 함수 훅(모드)을 지원하는 Claude Code. Claude Code **2.1.301**에서 만들고 시험했다. 모드 API는 early access라 릴리스마다 바뀔 수 있다.
- 터미널용으로 만들었다. 전체화면 레이아웃에서 패널이 오른쪽에 붙는다. 데스크톱 앱은 Claude Code의 플러그인 시험으로만 확인했고 직접 써 보지는 않았다.
