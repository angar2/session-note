# session-note

**Claude Code 모드(mod) 플러그인** — 세션마다 노트를 하나 붙여, 해야 할 일·확인할 일을 나와 에이전트가 함께 적고 함께 완료 처리해요. 여러 단계짜리 일은 세션이 과정을 짜서 지금 어느 단계인지 보여 줘요.

[English](README.md)

![session-note 동작 시연: 버그 수정을 맡기면 세션이 과정을 짜 띠 오른쪽에 지금 단계를 띄우고, 미룬 일을 할 일로 제안해 추가하고, 패널의 과정 탭에서 단계를 본 뒤 "4번 빼 줘"라고 하자 단계가 빠지고 번호가 다시 매겨지는 화면](docs/demo-ko.gif)

## 소개

session-note는 Claude Code의 **모드(mod) 플러그인**이에요. 모드는 플러그인이 Claude Code 화면 안에 직접 부품을 그릴 수 있게 해 주는 기능이에요. 그래서 노트가 별도 창이 아니라 입력창 바로 위와 터미널 옆 패널에 붙어서 보여요.

에이전트와 한참 작업하다 보면 이런 말을 자주 하게 돼요.

- "그건 일단 넘어가고 나중에 보자."
- "이거 맞는지 확인해 봐야겠다."
- "끝나면 테스트도 한번 돌려 보자."

말할 때는 당연히 기억할 것 같지만, 대화가 길어지면 이런 말은 위로 밀려 올라가 금방 사라져요. 에이전트도 내가 먼저 꺼내지 않으면 다시 떠올리지 않고요. 그렇게 미뤄 둔 일이 조용히 잊혀요.

session-note는 세션마다 작은 노트를 하나 붙여 줘요. 미뤄 둔 일과 확인할 일을 노트의 **할 일**에 적어 두고, 끝나면 완료 처리하면 돼요. 노트는 입력창 바로 위에 늘 보이고, 에이전트도 같은 노트를 보면서 함께 챙겨 줘요.

여러 단계짜리 일을 맡기면 세션이 그 일의 순서를 노트의 **과정**으로 짜요. 과정은 세션이 직접 짜고 일이 진행되는 대로 갱신하는 로드맵이에요. 입력창 위만 봐도 지금 어느 단계인지 알 수 있고, 다른 일을 하다 돌아와도 어디까지 왔는지 바로 찾을 수 있어요.

## 주요 기능

- **남은 일이 늘 보여요.** 입력창 위에 남은 할 일 수가 떠 있어서, 세션을 닫기 전에 한 번 더 확인하게 돼요.
- **에이전트가 먼저 제안해요.** 대화 중에 "나중에 보자"가 나오면 에이전트가 할 일로 넣자고 제안해요. 버튼만 누르면 돼요.
- **끝난 일을 알려 줘요.** 작업을 마치면 에이전트가 할 일을 훑어보고, 끝난 것 같은 항목을 완료하자고 제안해요.
- **할 일은 언제나 내가 정해요.** 에이전트는 할 일을 제안만 하고, 내가 버튼을 누르거나 말로 시키기 전에는 할 일을 바꾸지 않아요.
- **지금 단계가 보여요.** 여러 단계짜리 일을 맡기면 세션이 과정을 짜고, 입력창 위에 지금 단계를 띄워요. 패널에서는 지나온 단계와 남은 단계를 한눈에 볼 수 있어요.
- **과정은 말로 고쳐요.** 과정은 세션이 일하면서 직접 짜고 고쳐요. 바꾸고 싶으면 "3번 빼 줘", "이거 2번 앞에 넣어 줘"처럼 말하면 바로 바뀌고 번호도 다시 매겨져요.
- **세션이 무거워지지 않아요.** 노트 내용을 답변마다 에이전트에게 다시 보내지 않고, 바뀐 것만 그때그때 짧게 전해요.

## 설치

Claude Code 안에서 아래 두 줄을 차례로 입력하세요.

```
/plugin marketplace add angar2/session-note
/plugin install session-note@angar2
```

- 첫 줄은 이 리포를 플러그인을 받아 올 곳으로 등록해요.
- 둘째 줄은 플러그인을 설치해요. 설치한 뒤에 여는 모든 세션에 노트가 붙어요.

## 사용 방법

### 띠 구성

입력창 바로 위 한 줄(이하 **띠**)은 왼쪽과 오른쪽 두 구역으로 나뉘어요.

```
 ☑ 할 일 2                                           ≡ 과정 ◼ 2.1 로그 읽기  열기
```

- 왼쪽 `☑ 할 일 2`는 남은 할 일 수예요. 에이전트의 제안도 이 옆에 떠요.
- 오른쪽 `≡ 과정 ◼ 2.1 로그 읽기`는 세션이 지금 하고 있는 단계예요. 진행 중인 단계가 없으면 비어 있어요.
- 맨 오른쪽 `열기`는 패널을 여는 버튼이에요. 제안이 와도 늘 그 자리에 있어요.
- 창이 좁으면 단계 제목부터 `…`로 줄어들고, 이름표·번호·버튼은 그대로 남아요.

### 에이전트의 제안 받기

대화 중에 "토큰 만료 처리는 나중에 확인하자"라고 말하면, 에이전트가 띠 왼쪽에 제안을 띄워요.

```
 ☑ 할 일 2  │  [+]  토큰 만료 처리 확인 [추가] [무시]     ≡ 과정 ◼ 2.1 로그 읽기  열기
```

- 파란 `[+]`는 "새 항목으로 넣을까요?"라는 뜻이에요.
- 노트에 넣으려면 `[추가]`를, 필요 없으면 `[무시]`를 누르세요.
- 제안은 답할 때까지 띠에 남아 있으니, 하던 대화를 먼저 마쳐도 괜찮아요.

### 완료 제안 받기

그 작업을 마치면 에이전트가 노트와 견주어 보고 완료를 제안해요.

```
 ☑ 할 일 2  │  [✓]  토큰 만료 처리 확인 [완료] [아직]     ≡ 과정 ◼ 2.1 로그 읽기  열기
```

- 초록 `[✓]`는 "이 항목은 끝난 것 같아요"라는 뜻이에요.
- 맞으면 `[완료]`를, 아직 남았으면 `[아직]`을 누르세요.
- 제안이 여러 개 쌓이면 띠에는 `[+] 새 항목 2 · [✓] 끝난 항목 1`처럼 개수만 보이고, 맨 오른쪽 `열기`가 `보기`로 바뀌어요. `보기`를 누르면 패널에서 하나씩 답할 수 있어요.

### 과정 따라가기

"로그인 버그 고쳐 줘", "1.1.0 배포 진행해 줘"처럼 여러 단계짜리 일을 맡기면 세션이 과정을 짜고 한 줄로 알려 줘요. 짧은 문답에는 과정을 짜지 않아요.

```
 ☑ 할 일 1                                                ≡ 과정 ◼ 1 재현  열기
 ☑ 할 일 1                                           ≡ 과정 ◼ 2.1 로그 읽기  열기
```

- 띠 오른쪽에 지금 단계가 번호와 함께 보여요. 세션이 다음 단계로 넘어가면 바로 바뀌어요.
- 진행 중인 단계가 서로 다른 큰 단계에 흩어져 있으면 앞쪽 하나와 `외 1`처럼 나머지 개수가 보여요.
- 세션이 내 답을 기다리는 동안처럼 진행 중인 단계가 없으면 과정 구역은 비어 있어요.

### 패널에서 할 일 관리하기

띠 맨 오른쪽의 `열기`를 누르거나 `/note`를 입력하면 터미널 오른쪽에 **패널**이 열려요. 창이 좁으면 입력창 위에 열려요.

패널 맨 위에는 `☑ 할 일 2    ≡ 과정 1`처럼 탭 두 개가 있어요. 숫자는 남은 할 일 수와 끝나지 않은 과정 수예요. 탭을 누르면 바뀌고, 패널을 다시 열면 마지막으로 본 탭이 열려요.

`할 일` 탭은 이렇게 써요.

- 위에서부터 답하지 않은 제안, 열린 항목, `+ 새 항목`, 완료된 항목 순서로 보여요.
- 항목을 직접 추가하려면 `+ 새 항목`을 누르고 제목과 내용을 적은 뒤 `[추가]`를 누르세요. 직접 쓴 항목에는 `☺` 표시가 붙어요.
- 항목을 완료하려면 앞의 `☐`를 누르세요. 완료된 항목의 `☑`를 다시 누르면 열린 항목으로 돌아와요.
- 제목을 누르면 내용과 추가한 시각, `[수정]` `[삭제]` 버튼이 펼쳐져요.

모든 조작은 마우스로 해요. 키보드는 제목과 내용을 입력할 때만 쓰면 돼요.

### 패널에서 과정 보기

`≡ 과정` 탭을 누르면 과정 전체가 보여요.

```
◼ 로그인 버그 수정
  ◼ 1 재현
  ◼ 2 원인 찾기 ▾
    ◼ 2.1 로그 읽기
    ◻ 2.2 가설 세우기
  ◻ 3 고치기
  ◻ 4 테스트 추가

◻ 1.1.0 배포 ▸  3에서 멈춤

──────────────────────
끝난 과정 1 ▸
```

- 맨 위가 지금 진행 중인 과정이고, 지금 단계는 굵게 보여요.
- 단계 앞 네모가 상태예요. `◻`는 대기, 파란 `◼`는 진행 중, 초록 `◼`는 완료, 빨간 `◼`는 중단이에요.
- 번호는 화면이 자리 순서대로 매겨요. 단계를 빼거나 끼워 넣으면 번호가 저절로 다시 매겨져요.
- 아래 단계가 있는 단계에는 `▸`가 붙어요. 제목을 누르면 `▾`로 바뀌며 아래 단계가 펼쳐져요. 처음에는 진행 중인 단계만 펼쳐져 있어요.
- 다른 일을 먼저 하느라 멈춘 과정은 `3에서 멈춤`처럼 멈춘 자리와 함께 한 줄로 접혀 있어요. 눌러서 펼쳐 볼 수 있어요.
- 끝난 과정은 지워지지 않고 맨 아래 `끝난 과정 N ▸`에 모여요.
- 과정 탭은 보기만 해요. 과정을 고치고 싶으면 에이전트에게 말로 시키세요.

### 대화로 노트 관리하기

에이전트에게 말로 시키면 제안을 거치지 않고 바로 처리해 줘요.

**할 일**

| 이렇게 말하면 | 에이전트가 하는 일 |
|---|---|
| "이거 노트에 남겨 줘" | 항목을 추가해요 |
| "그거 끝났어" | 그 항목을 완료해요 |
| "그 항목 제목 바꿔 줘" | 항목을 수정해요 |
| "그거 지워 줘" | 항목을 삭제해요 |
| "노트 확인해 줘" | 열린 항목을 훑어보고, 끝난 것을 완료하자고 제안해요 |

할 일은 시키지 않은 수정이나 삭제를 하지 않으니 안심하세요.

**과정**

| 이렇게 말하면 | 에이전트가 하는 일 |
|---|---|
| "3번 빼 줘" | 지금 과정에서 3번 단계를 빼요 |
| "이거 2번 앞에 넣어 줘" | 2번 앞에 단계를 끼워 넣어요 |
| "4번을 2번 뒤로 옮겨 줘" | 단계 순서를 바꿔요 |
| "배포는 멈추고 이 버그부터 보자" | 새 과정을 짜서 진행하고, 하던 과정은 멈춘 자리를 기억해 둬요 |
| "그 과정 지워 줘" | 과정을 지워요 |

과정은 세션이 일하면서 직접 고쳐요. 단계를 넘기거나 아래 단계를 채울 때는 따로 말하지 않고, 큰 줄기를 바꿀 때만 이유를 한 줄로 알려 줘요.

## 설정

`/plugin configure session-note@angar2`에서 언제든 바꿀 수 있어요. 설정을 바꿔도 노트의 항목은 그대로 남아요.

| 설정 | 고를 수 있는 값 | 기본값 | 설명 |
|---|---|---|---|
| Language | English · 한국어 | English | 띠와 패널에 쓰이는 언어예요 |
| Band background | None · Gray · Olive · Wine | None | 띠의 배경색이에요. 띠를 더 눈에 띄게 하고 싶을 때 골라 보세요 |

배경색은 쓰고 있는 터미널 테마에 맞춰 칠해져요.

## 세션과 저장

### 세션별 노트

- 노트는 세션마다 따로 있어요.
- `/clear`를 하면 새 세션이 시작되므로 빈 노트로 시작해요. 이전 노트는 이전 세션에 그대로 남아 있어요.
- `/resume`으로 이전 세션을 다시 열면 그 세션의 노트도 함께 돌아와요.
- 대화가 압축되거나 `/resume`으로 돌아오면 세션은 노트의 할 일과 과정을 다시 전해 받아, 하던 단계부터 이어 가요.

### 저장 위치

노트는 세션마다 JSON 파일 하나로 저장돼요.

```
~/.claude/plugins/data/session-note-angar2/sessions/<세션 ID>.json
```

**플러그인을 삭제하면 노트도 함께 지워지니 주의하세요.** 노트를 남겨 두려면 삭제할 때 `--keep-data`를 붙이세요.

```sh
claude plugin uninstall session-note@angar2 --keep-data
```

## 제한 사항

- **회사가 관리하는 Claude Code**에서는 개인이 설치한 플러그인에 세션 시작 신호가 오지 않아요. 그래서 `/clear`나 `/resume`을 해도 노트가 바뀌지 않아요.
- **`/rewind`**로 대화를 되감아도 노트는 되감기지 않아요. 에이전트는 노트를 다시 읽어서 최신 상태를 알 수 있어요.
- **같은 세션을 터미널 두 개에서 동시에 열면** 나중에 저장한 쪽만 남아요.

## 요구 사항

- 모드(플러그인 함수 훅)를 지원하는 Claude Code가 필요해요. Claude Code 2.1.301에서 만들고 시험했어요.
- 모드 기능은 아직 early access라서, Claude Code 버전이 바뀌면 동작이 달라질 수 있어요.
