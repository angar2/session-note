# session-note

**Claude Code 모드(mod) 플러그인** — 세션마다 노트를 하나 붙여, 해야 할 일·확인할 일을 나와 에이전트가 함께 적고 함께 완료 처리해요.

[English](README.md)

![에이전트가 미룬 일을 노트에 제안하고, 일이 끝나면 완료를 제안하고, 패널에서 직접 항목을 추가·완료하는 모습](docs/demo-ko.gif)

## 소개

session-note는 Claude Code의 **모드(mod) 플러그인**이에요. 모드는 플러그인이 Claude Code 화면 안에 직접 부품을 그릴 수 있게 해 주는 기능이에요. 그래서 노트가 별도 창이 아니라 입력창 바로 위와 터미널 옆 패널에 붙어서 보여요.

에이전트와 한참 작업하다 보면 이런 말을 자주 하게 돼요.

- "그건 일단 넘어가고 나중에 보자."
- "이거 맞는지 확인해 봐야겠다."
- "끝나면 테스트도 한번 돌려 보자."

말할 때는 당연히 기억할 것 같지만, 대화가 길어지면 이런 말은 위로 밀려 올라가 금방 사라져요. 에이전트도 내가 먼저 꺼내지 않으면 다시 떠올리지 않고요. 그렇게 미뤄 둔 일이 조용히 잊혀요.

session-note는 세션마다 작은 노트를 하나 붙여 줘요. 미뤄 둔 일과 확인할 일을 노트에 적어 두고, 끝나면 완료 처리하면 돼요. 노트는 입력창 바로 위에 늘 보이고, 에이전트도 같은 노트를 보면서 함께 챙겨 줘요.

## 주요 기능

- **남은 일이 늘 보여요.** 입력창 위에 열린 항목 수가 떠 있어서, 세션을 닫기 전에 한 번 더 확인하게 돼요.
- **에이전트가 먼저 제안해요.** 대화 중에 "나중에 보자"가 나오면 에이전트가 노트에 넣자고 제안해요. 버튼만 누르면 돼요.
- **끝난 일을 알려 줘요.** 작업을 마치면 에이전트가 노트를 훑어보고, 끝난 것 같은 항목을 완료하자고 제안해요.
- **결정은 언제나 내가 해요.** 에이전트는 제안만 하고, 내가 버튼을 누르거나 말로 시키기 전에는 노트를 바꾸지 않아요.
- **세션이 무거워지지 않아요.** 노트 내용을 답변마다 에이전트에게 다시 보내지 않고, 바뀐 것만 그때그때 짧게 전해요.

## 설치

Claude Code 안에서 아래 두 줄을 차례로 입력하세요.

```
/plugin marketplace add angar2/session-note
/plugin install session-note@angar2
```

- 첫 줄은 이 리포를 플러그인을 받아 올 곳으로 등록해요.
- 둘째 줄은 플러그인을 설치해요. 설치한 뒤에 여는 모든 세션에 노트가 붙어요.

## 사용 방법

### 에이전트의 제안 받기

대화 중에 "토큰 만료 처리는 나중에 확인하자"라고 말하면, 에이전트가 입력창 위 한 줄(이하 **띠**)에 제안을 띄워요.

```
 노트 2  │  [+]  토큰 만료 처리 확인                              [추가] [무시]
```

- 파란 `[+]`는 "새 항목으로 넣을까요?"라는 뜻이에요.
- 노트에 넣으려면 `[추가]`를, 필요 없으면 `[무시]`를 누르세요.
- 제안은 답할 때까지 띠에 남아 있으니, 하던 대화를 먼저 마쳐도 괜찮아요.

### 완료 제안 받기

그 작업을 마치면 에이전트가 노트와 견주어 보고 완료를 제안해요.

```
 노트 2  │  [✓]  토큰 만료 처리 확인                              [완료] [아직]
```

- 초록 `[✓]`는 "이 항목은 끝난 것 같아요"라는 뜻이에요.
- 맞으면 `[완료]`를, 아직 남았으면 `[아직]`을 누르세요.
- 제안이 여러 개 쌓이면 띠에는 `[+] 새 항목 2 · [✓] 끝난 항목 1`처럼 개수만 보여요. `보기`를 누르면 패널에서 하나씩 답할 수 있어요.

### 패널에서 노트 관리하기

띠 오른쪽의 `열기`를 누르거나 `/note`를 입력하면 터미널 오른쪽에 **패널**이 열려요. 창이 좁으면 입력창 위에 열려요.

- 위에서부터 답하지 않은 제안, 열린 항목, `+ 새 항목`, 완료된 항목 순서로 보여요.
- 항목을 직접 추가하려면 `+ 새 항목`을 누르고 제목과 내용을 적은 뒤 `[추가]`를 누르세요. 직접 쓴 항목에는 `☺` 표시가 붙어요.
- 항목을 완료하려면 앞의 `☐`를 누르세요. 완료된 항목의 `☑`를 다시 누르면 열린 항목으로 돌아와요.
- 제목을 누르면 내용과 추가한 시각, `[수정]` `[삭제]` 버튼이 펼쳐져요.

모든 조작은 마우스로 해요. 키보드는 제목과 내용을 입력할 때만 쓰면 돼요.

### 대화로 노트 관리하기

에이전트에게 말로 시키면 제안을 거치지 않고 바로 처리해 줘요.

| 이렇게 말하면 | 에이전트가 하는 일 |
|---|---|
| "이거 노트에 남겨 줘" | 항목을 추가해요 |
| "그거 끝났어" | 그 항목을 완료해요 |
| "그 항목 제목 바꿔 줘" | 항목을 수정해요 |
| "그거 지워 줘" | 항목을 삭제해요 |
| "노트 확인해 줘" | 열린 항목을 훑어보고, 끝난 것을 완료하자고 제안해요 |

시키지 않은 수정이나 삭제는 하지 않으니 안심하세요.

## 설정

`/plugin configure session-note@angar2`에서 언제든 바꿀 수 있어요. 설정을 바꿔도 노트의 항목은 그대로 남아요.

| 설정 | 고를 수 있는 값 | 기본값 | 설명 |
|---|---|---|---|
| Language | English · 한국어 | English | 띠와 패널에 쓰이는 언어예요 |
| Band background | None · Gray · Olive · Wine | None | 띠의 배경색이에요. 띠를 더 눈에 띄게 하고 싶을 때 골라 보세요 |

배경색은 쓰고 있는 터미널 테마에 맞춰 칠해져요.

## 세션과 저장

### 세션별 노트

- 노트는 세션마다 따로 있어요.
- `/clear`를 하면 새 세션이 시작되므로 빈 노트로 시작해요. 이전 노트는 이전 세션에 그대로 남아 있어요.
- `/resume`으로 이전 세션을 다시 열면 그 세션의 노트도 함께 돌아와요.

### 저장 위치

노트는 세션마다 JSON 파일 하나로 저장돼요.

```
~/.claude/plugins/data/session-note-angar2/sessions/<세션 ID>.json
```

**플러그인을 삭제하면 노트도 함께 지워지니 주의하세요.** 노트를 남겨 두려면 삭제할 때 `--keep-data`를 붙이세요.

```sh
claude plugin uninstall session-note@angar2 --keep-data
```

## 제한 사항

- **회사가 관리하는 Claude Code**에서는 개인이 설치한 플러그인에 세션 시작 신호가 오지 않아요. 그래서 `/clear`나 `/resume`을 해도 노트가 바뀌지 않아요.
- **`/rewind`**로 대화를 되감아도 노트는 되감기지 않아요. 에이전트는 노트를 다시 읽어서 최신 상태를 알 수 있어요.
- **같은 세션을 터미널 두 개에서 동시에 열면** 나중에 저장한 쪽만 남아요.

## 요구 사항

- 모드(플러그인 함수 훅)를 지원하는 Claude Code가 필요해요. Claude Code 2.1.301에서 만들고 시험했어요.
- 모드 기능은 아직 early access라서, Claude Code 버전이 바뀌면 동작이 달라질 수 있어요.
